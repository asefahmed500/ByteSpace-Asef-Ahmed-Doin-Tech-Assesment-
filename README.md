# ByteSpace-Asef-Ahmed-Doin-Tech-Assesment-

ByteSpace — an online course platform UI, built from Figma designs with Next.js 16 (App Router, Turbopack), React 19, Tailwind CSS v4 and TypeScript.

## Pages

- `/` — Home (hero, partners, courses, categories, features, CTA, testimonials)
- `/courses` — Course catalog with filters and pagination
- `/courses/[slug]` — Course details (About)
- `/courses/[slug]/lessons` — Course lessons
- `/courses/[slug]/reviews` — Course reviews
- `/creators` — Creator profile
- `/login` & `/register` — Auth pages
- Branded 404

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.
